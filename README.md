# গারান্টি রিলিজ ট্র্যাকার (টেস্ট ভার্সন)

মাস্টার ফাইলের গারান্টি (সিকিউরিটি মানি) ট্র্যাক করার সফটওয়্যারের ক্লিক করে দেখার মতো নমুনা: ডিপো রিসিভিং → সার্ভে → এজেন্টকে জমা → এজেন্টের হিসাব → রিলিজ।

**লাইভ:** https://jhtanjim.github.io/document-release-dipu/

## যা আছে

- **ড্যাশবোর্ড:** সার্ভে লেট, হিসাব লেট, ওভারডিউ ফাইলের সংখ্যা; ইম্পোর্টার অনুযায়ী প্লাস ও মাইনাস।
- **সব ফাইল:** ফিল্টার, খোঁজা, যেকোনো ফাইল আপডেট।
- **স্টেটমেন্ট:** All Files বা নির্দিষ্ট ইম্পোর্টার; হিসাব না এলে লাল "Pending"।
- **নতুন ফাইল:** সিকিউরিটি মানি = কন্টেইনার × রেট (ডিফল্ট ১০,০০০), ব্যালেন্স = সিকিউরিটি − আসল খরচ।

## নিয়ম

| মার্ক | কখন |
| --- | --- |
| সার্ভে লেট | ডিপো রিসিভিংয়ের ৭ দিনের বেশি পরেও সার্ভে রিপোর্ট নেই |
| হিসাব লেট | সার্ভে রিপোর্টের ৭ দিন বা বেশি পরেও এজেন্টের হিসাব নেই |
| ওভারডিউ | এজেন্টকে জমার ৩০ দিনের বেশি পরেও রিলিজ হয়নি |

দিনের সীমা আর ডিফল্ট রেট সেটিংস থেকে বদলানো যায়।

## টেস্ট নোট

- ৯টা নমুনা ফাইল দেওয়া আছে, সব বানানো ডেটা।
- উপরে "আজকের তারিখ (টেস্ট)" বদলালে দেখা যায় কোন ফাইল কবে লাল হয়।
- কোনো সার্ভার নেই: এন্ট্রি শুধু নিজের ব্রাউজারে (localStorage) থাকে।

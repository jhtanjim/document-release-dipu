# গারান্টি রিলিজ ট্র্যাকার (টেস্ট ভার্সন)

প্রতিটা জবের গারান্টি (সিকিউরিটি মানি) ট্র্যাক করার সফটওয়্যারের ক্লিক করে দেখার মতো নমুনা: ডিপো রিসিভিং → সার্ভে → শিপিং এজেন্টকে জমা → এজেন্টের হিসাব → রিলিজ।

**লাইভ:** https://document-release-dipu.vercel.app

## যা আছে

- **ড্যাশবোর্ড:** সার্ভে লেট, হিসাব লেট, ওভারডিউ জবের সংখ্যা; ইম্পোর্টার অনুযায়ী প্লাস ও মাইনাস।
- **সব জব:** ইম্পোর্টার ও এজেন্ট ফিল্টার, জব নং বা C নং দিয়ে খোঁজা, যেকোনো জব আপডেট।
- **স্টেটমেন্ট:** কোন ইম্পোর্টারের কোন শিপিং এজেন্টে কয়টা জব তার টেবিল; ইম্পোর্টার (All Jobs সহ) আর এজেন্ট দিয়ে ফিল্টার; হিসাব না এলে লাল "Pending"।
- **নতুন জব:** জব নং, C নং, ইম্পোর্টার (ইংরেজিতে), শিপিং এজেন্ট। সিকিউরিটি মানি = কন্টেইনার × রেট (ডিফল্ট ১০,০০০), ব্যালেন্স = সিকিউরিটি − আসল খরচ।

শিপিং এজেন্ট লিস্ট: APL Bangladesh Pvt Ltd, MSC Mediterranean Shipping, COSCO, Reliance Shipping, Maersk Line Bangladesh, Ocean Network Express (ONE), PIL Bangladesh Ltd, Hapag-Lloyd, SITC Bangladesh। লিস্টের বাইরের এজেন্টও এন্ট্রি দেওয়া যায়।

## নিয়ম

| মার্ক | কখন |
| --- | --- |
| সার্ভে লেট | ডিপো রিসিভিংয়ের ৭ দিনের বেশি পরেও সার্ভে রিপোর্ট নেই |
| হিসাব লেট | সার্ভে রিপোর্টের ৭ দিন বা বেশি পরেও এজেন্টের হিসাব নেই |
| ওভারডিউ | এজেন্টকে জমার ৩০ দিনের বেশি পরেও রিলিজ হয়নি |

দিনের সীমা আর ডিফল্ট রেট সেটিংস থেকে বদলানো যায়।

## টেস্ট নোট

- ১২টা নমুনা জব দেওয়া আছে, সব বানানো ডেটা।
- উপরে "আজকের তারিখ (টেস্ট)" বদলালে দেখা যায় কোন জব কবে লাল হয়।
- কোনো সার্ভার নেই: এন্ট্রি শুধু নিজের ব্রাউজারে (localStorage) থাকে।
